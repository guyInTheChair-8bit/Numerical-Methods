# Numerical Methods Projects

This collection contains C programs and supporting notes/data for numerical methods and computational science exercises. Each project has its own folder and README with a summary and basic build/run guidance.

## Projects

- [Droplet Detection and Analysis](Droplet/README.md) — smooths signal data and detects peaks and valleys.
- [Gaussian Elimination](Gauss/README.md) — solves a linear system with forward elimination and back substitution.
- [Hamming Distance Search](Hamming%20Distance/README.md) — compares codeword windows in a noisy bit block.
- [Polynomial Interpolation](Interpolation/README.md) — compares Newton and Lagrange interpolation.
- [2D Ising Model](Ising%20Model/README.md) — simulates spin-lattice magnetization with Metropolis updates.
- [Logistic Map](Logistic%20map/README.md) — generates and plots a logistic-map bifurcation diagram.
- [Linear System Solver](Matrix%20Inversion/README.md) — provides Gaussian and LU solution methods.
- [Two-Sample t-Test Simulation](ttest/README.md) — simulates samples and plots t-statistics.
