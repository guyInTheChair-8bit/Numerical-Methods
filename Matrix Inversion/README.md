# Linear System Solver

Solves an augmented linear system using Gaussian elimination or LU decomposition. The included `augmented_matrix.txt` is a sample 3 by 4 augmented matrix. Check the program's usage message for the expected command-line arguments and method names.

```sh
gcc linear_system_solver.c -o linear_system_solver
./linear_system_solver matrix.txt 3 Gaussian
```
